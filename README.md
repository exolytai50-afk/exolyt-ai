# CookAI - Интеллектуальная Кулинарная Платформа

## 🍳 Описание
CookAI — это полнофункциональное веб-приложение для управления рецептами, планирования питания и взаимодействия в кулинарном сообществе с использованием искусственного интеллекта.

## 🎯 Основные функции
- **AI Генератор рецептов** — создание персонализированных рецептов
- **Сканер калорий по фото** — анализ блюд через Computer Vision
- **План питания на неделю** — автоматическое планирование
- **Кулинарные книги** — организация рецептов в коллекции
- **Социальная сеть** — сообщества, рейтинги, челленджи, чат
- **Admin-панель** — управление контентом и модерация

## 📋 Требования
- PHP 8.0+
- MySQL 5.7+
- Веб-сервер с поддержкой .htaccess (Apache)
- Node.js (для сборки ассетов)

## 📁 Структура проекта
```
cookai/
├── public/              # Публичные файлы
│   ├── index.php       # Главная точка входа
│   ├── .htaccess       # Настройки Apache
│   ├── css/            # Стили
│   ├── js/             # JavaScript
│   └── img/            # Изображения
├── app/                # Приложение
│   ├── controllers/    # Контроллеры
│   ├── models/         # Модели
│   ├── views/          # Представления
│   ├── middleware/     # Middleware
│   └── config/         # Конфигурация
├── database/           # Миграции и seeds
├── storage/            # Загрузки и кеш
├── .env.example        # Пример переменных окружения
├── composer.json       # Зависимости PHP
└── package.json        # Зависимости Node.js
```

## 🚀 Установка
1. Клонируйте репозиторий
2. Скопируйте `.env.example` в `.env`
3. Установите зависимости: `composer install && npm install`
4. Создайте БД и запустите миграции
5. Запустите приложение
